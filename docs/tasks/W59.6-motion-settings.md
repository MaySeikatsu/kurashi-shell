Brief `docs/ux/motion-engine.md` §8 (the page), §3 (precedence and provenance), §11 (reduce motion); contract
`W59-motion-engine.md`; K83. Common rules `docs/tasks/README.md`. Model: Opus. UX-heavy: look at cubic-bezier.com,

## Build
- The page from the schema (`page = "motion"`), with the gallery, preview and the two custom controls (brief §8).
- **Curve control**: graph with two handles, linear reference, overshoot band; tabs Cubic · Spring · Steps · Presets;
  paste field (canonical, CSS `cubic-bezier()`, easings.net names, Hyprland `x0, y0, x1, y1`, `spring(…)`); spring tab:
  duration + bounce, Advanced stiffness/damping, the response plot with overshoot % and settle time (from the daemon's
  sampled plot if exposed, else computed with `curves.js`); invalid input explains itself and applies nothing;
  "Save as preset…" (a name → a user pack `[curves]`; the daemon reloads packs) — if writing a pack needs a daemon intent,
  file a CONTRACT-CHANGE row and keep the button inert with its reason until the lead adds it.
- **Preview**: imports the frontend's `components/motion` (the same forms, not copies); a mini bar with a button per
  surface class; speed ½× ¼×; scrubber on `Driver.track`; Compare (hold) = the previous value; plays on change and on
  demand only, stops when the window is hidden (Ma).
- The forms table: the island row has the **Follow the default** switch (`theme.motion.island.follow`); while it is on,
  its own pickers read inert with the reason and show what it follows.
- Provenance on every row ("from profile Origami (style Kami)", "yours · Reset to …"), inert reasons under reduce motion.
- Keyboard and a11y as brief §8 (handles, arrows, Shift, Enter/Esc, accessible names); ja layout checked.
