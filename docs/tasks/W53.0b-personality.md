## Scope
1. Lock faces: `FaceBase`/`PlainFace`, `lock.face = follow | plain | <name>` (default `follow`), greeter hosting,
   `caps_lock` + `fingerprint` in `runtime.lock`.
2. Stage-card title bars: switch `off | close only | full`, configurable button actions (close = close, maximize = full
   screen, minimize = the app's own bar menu where it fits, else hide); no inert buttons.
3. Sounds: a per-style cue profile (off by default, one switch), a refcounted daemon player (no idle cost),
   `sounds/<style>/` original files only (placeholders acceptable; the family cards add the real sets).
4. Cursor personality (I317), both off by default: a cursor theme per style written by kurashid as a niri include (as
   keys do), and a cursor decoration (trail like osu!, sparkles, ring) on an effects sheet that exists only while it runs
   (I312), fed by `svc.pointer` (K79; fallback: no trail outside the shell's surfaces).
5. A bar `launcher` module (start button / Apple-menu dress) opening the launcher in a start-menu skin slot.
6. Layout presets: `profiles/<style>-desk.toml` plumbing + Settings' "Also use its layout" offer (never applied by itself).
