# W59.7 — custom forms as recipes (declarative, user packs)

Brief `docs/ux/motion-engine.md` §5 "Custom forms" tier 1; contract `W59-motion-engine.md` (`motion.recipe.<id>`, pack
`[recipes.<id>]`); K83. Common rules `docs/tasks/README.md`. Model: Opus.

## Goal
A user writes a form without code — in a user motion pack — and picks it like a built-in, with Settings' preview showing it.

## Owned paths
`crates/kurashi-motion/src/recipe.rs` (+ its tests, its call in `resolve.rs`) · `frontend/components/motion/forms/Recipe.qml`
· `settings/components/motion/RecipeList.qml` (list, validation messages, "open the pack file", preview) ·
`i18n/{en,ja}/motion.toml` recipe keys (append-only section) · `docs/ux/motion-engine.md` §5 (the recipe reference, with
three worked examples).

## Build
- Recipe format: `[recipes.<id>] label = "…"; base = "<form>"? ; [[recipes.<id>.track]] prop, keys = [[p, v], …],
  curve = "<curve>"?, unit = "fraction"|"px"`. Props: `opacity scale scale_x scale_y translate_along translate_across
  rotate_x rotate_y rotate_z skew_x skew_y blur clip_inset clip_iris clip_wipe` and, with a sheet `base`, that form's params
  (`fold.panels` is not animatable — params that are, are declared in the forms meta).
- Validation with reasons (`config.diag.recipe.*`): unknown prop, keys not ascending in p or outside [0,1], values out of
  range (opacity 0–1, scale 0–3, rotate −180…180, blur 0–64), > 12 tracks, > 16 keys a track. A bad recipe is skipped with
  its diagnostic; a profile naming it falls back to its default form.
- `Recipe.qml`: evaluates every track from the host's one progress (no timers, Ma); a `blur` track enables the layer only
  while moving; `vestibular` flag set automatically if |rotate| > 30° or scale outside 0.8–1.2 (reduce motion skips it).

## Acceptance
`cargo test -p kurashi-motion` (format, every diag, fallback); a user pack in the niri sandbox with the three brief
examples ("pop and tilt", "drop and squash", "slide with blur") → listed in Settings, previewed, applied to a panel;
scrubbed shots at 0.25/0.5/0.75/1; p = 1 equals motion-off; idle 0.
