# W53.0-system — the design system grows to carry every style's personality (K80)

First card of wave W53 (the styles, `docs/tasks/W53-styles.md`); W53.1–W53.8 run in parallel worktrees after it merges.
Brief: `docs/ux/styles.md` (its "The shared system" section and "Decided" 1–11). Common rules: `docs/tasks/README.md`.
Opus. Build dir `CARGO_TARGET_DIR=$HOME/.cache/kurashi-agents-target/W53.0-system`.

## Goal
Everything a style needs to look 1:1 like its inspiration becomes data — decor-pack slots, `[decor]` metrics and tokens
(rule 4: renderers bind to slots and tokens, never to a style's name) — so a family card only writes toml, decor parts
and a lock face. The user (session 18): extend the system wherever it keeps a style from a 1:1 look.

1. **Slots and metrics.** Look slots for title bars, start dress, tray well, menu, scroll bar, tooltip, focus ring,
   button/slider/toggle faces; a `[decor]` metrics table (title bar height, border/bevel widths and colours, menu row
   height, separators, scroll bar width…); new palette roles the brief lists. Schema + tokens + migration.
2. **Chrome.** A `bevel` chrome next to flat/keycap/soft/line (light/dark outer and inner pairs, `sunken` wells);
   under high contrast the bevel stays in high-contrast colours (K80 amends K42).
3. **Motion personality.** Animation *styles* per style (slide, zoom, fade, flip, `stepped`/pixel, rubber band) and
   its own motion curves and timings (béziers per role), on top of K74's profiles; reduced motion still wins.
4. **Type and symbols.** Font chains per style with free stand-ins installed by Home-Manager (Decided 4); icon sets
   and icon sizes per style (a style may bring its own symbol font or SVG set; sizes as tokens).
5. **Materials.** Bloom and glow next to blur and the existing materials (Aero's glass glow, Vista/7 sheen); budgets
   per effect, 0 frames idle.
6. **Lock faces.** `FaceBase`/`PlainFace`, `lock.face = follow | plain | <name>` (default `follow`), greeter hosting,
   `caps_lock` and `fingerprint` in `runtime.lock` (contract change: fixtures + PROTOCOL + DECISIONS).
7. **Title bars on Stage cards** with a switch `off | close only | full` and configurable button actions (defaults:
   close = close, maximize = full screen, minimize = the app's own bar menu where it fits, else hide) — no button that
   does nothing (Shōjiki).
8. **Sounds plumbing.** A sound-cue profile per style (every style may have one; off by default; one switch), played by
   the daemon (refcounted player, no idle cost); `sounds/<style>/` with original files only.
9. **Layout presets.** Every style ships a companion layout profile (`profiles/<style>-desk.toml`), offered with the
   style ("Also use its layout"), never applied by itself (K45).
10. **Start button.** A bar `launcher` module (the start/Apple-menu dress) that opens the launcher/console in the style's
    start-menu skin (a launcher skin slot).
11. **Cursor personality, off by default** (I317): a cursor theme per style applied through the compositor (a
    kurashid-written niri include, as keys do; sway/Hyprland adapters), and a cursor decoration (trail as in osu!,
    sparkles, ring) on the effects sheet (I312) fed by `svc.pointer` (K79). Both switches off by default.
12. **`frontend/test-styles.sh`**: every style × 7 surfaces (bar, island card, sidebar, dock, launcher, toast, lock) shot
    on niri into `frontend/shots/styles/<style>/`.
