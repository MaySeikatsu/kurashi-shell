Half of W53.0 (`docs/tasks/W53.0-system.md`: read it whole — goal items 1–5 and 12 are this card's); W53.0b runs beside it
with disjoint paths. Brief: `docs/ux/styles.md` ("The shared system", "Decided" 1–11). Rules: `docs/tasks/README.md`,

## Scope
1. Look slots + a `[decor]` metrics table + new palette roles (schema, `appearance.rs` LOOK_KEYS, tokens, migration).
2. `bevel` chrome (outer/inner light-dark pairs, `sunken` wells) in `Block.qml`; high contrast keeps it (K80 amends K42).
3. Animation styles (slide, zoom, fade, flip, stepped, rubber band) and per-style curves/timings as tokens on top of K74;
   reduced motion wins.
4. Font chains + icon set and icon-size tokens per style; Home-Manager installs the free stand-ins (licences permitting).
5. Bloom/glow material effect next to blur (budgeted; 0 frames idle).
6. Decor hosts in `frontend/components/decor/` (title bar, tray well, menu, scroll bar, tooltip, focus-ring styles) with
   defaults that keep every current look pixel-identical; `frontend/test-styles.sh` (styles × 7 surfaces on niri).
