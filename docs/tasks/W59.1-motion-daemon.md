# W59.1 — the daemon side: `kurashi-motion`, motion packs, tokens (today bit-exact)

Brief `docs/ux/motion-engine.md` §3, §4, §9; contract `W59-motion-engine.md` (frozen — requests go to CONTRACT-CHANGE);
K83. Common rules `docs/tasks/README.md`. Model: Opus.

## Goal
One pure crate owns curves, springs, packs and the resolution of a motion profile into tokens; `kurashi-theme` calls it.
Every style's resolved tokens for today's keys stay **identical** (golden), the new token families appear.

## Owned paths
`crates/kurashi-motion/**` (new; `[lints] workspace = true`) · `motion/*.toml` (built-in packs) ·
`crates/kurashi-theme/src/tokens.rs` (the §motion block only: replace the inline derivation by calls) ·
`crates/kurashi-theme/src/appearance.rs` (drop the `motion.*` decor keys from the decor key list) · `looks/{fluent,aqua,
material,snes,ps2,kawaii}.toml` (remove their `motion.*` lines) · `styles/*.toml` (`[recipe] "theme.motion.profile"`
for those six) · the pack loader's data-dir wiring in kurashid (one call site) · tests in those crates.

## Build
- `curve.rs`: `Curve { Cubic(Vec<f64>), Spring{response_ms, bounce}, SpringQ{spring, damping}, Steps(n), Linear, None }`,
  parse/format (canonical strings, brief §4; Hyprland `x0, y0, x1, y1` and easings.net names accepted on input, written
  back canonical), validation with `config.diag.curve.*` keys, presets table (brief §4) incl. `snap`, `drop`, `paper`,
  `anticipate` as concrete segments (write them, plot them in a test helper, check monotonic x and the stated overshoots).
- `spring.rs`: response/bounce ↔ stiffness/damping (mass 1), closed-form position/velocity (under/critical/over-damped),
  settle time (|x−1| < 0.001), sampled plot for Settings (64 points), niri mapping (`damping-ratio`, `stiffness`).
- `pack.rs`: load built-in + user packs (user dir wins by id; a broken pack → diag, skipped), schema of the TOML in the
  contract; `stepped` as `steps(n)` with n from duration and `motion.steps` as today's `stepped_curve`.
- `resolve.rs`: `(profile id, user axes, a11y, speed) → tokens` per the contract's precedence; legacy tokens derived
  from the result exactly as tokens.rs did (move its code, don't re-derive numbers).
- Forms meta: the table of every form id in the brief §5 (family, surfaces, retarget, overshoot, flags, tier), also for
  forms not built yet: those carry `"available": false`, are not listed in Settings until their card merges, and the
  schema rejects them with a reason (`config.diag.form.unavailable`).

## Acceptance
`timeout 600 cargo test -p kurashi-motion -p kurashi-theme` with: a golden of the full token map for **every style ×
{expressive, calm, lively, none}** captured on `main` before the change and equal after (except the added keys); curve
round-trip proptests; spring settle-time and overshoot tests against the closed form; a user pack overriding a built-in
id; a pack with a bad curve → diag and fallback. `cargo clippy -p kurashi-motion --all-targets -- -D warnings`.
