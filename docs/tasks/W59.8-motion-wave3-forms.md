## Build (each on `SheetForm.qml`; read W59.4's Fold.qml first as the pattern)
- `fan`: N ribs (5–12) about a pivot at the origin's centre; rib k opens on its own sub-progress (lag 0.06); the paper
  between ribs stretches; rib lines in the look's outline role.
- `noren`: N vertical strips (3–7, by width) drop from the hinge with stagger, each a damped pendulum (≤ 4°) that settles
  by p = 1.
- `pixelate`: block size 32 → 16 → 8 → 4 → 2 → 1 px in held steps (device pixels), content sampled at block centres.
- `glitch`: 6–10 horizontal slices offset ±(1 − p)·24 px with RGB split ≤ 3 px, decaying; no full-surface flicker;
  ≤ 3 changes per second of luminance > 20 % (flag `flash` otherwise).
- `dissolve`: a value-noise threshold sweeping with p, a 2-px glowing edge in the pack's `edge` role (embers).
