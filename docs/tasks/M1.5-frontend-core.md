# Card M1.5-frontend-core — frontend core API + run against the real daemon

**Goal.** Make `frontend/core` the stable base the UI cards build on: on-demand documents,
queries, actions/intents — and make the shell run against the **real `kurashid`** (it still works
with the mock).

**Owned paths:** `frontend/core/`, `frontend/shell.qml`, `frontend/README.md`, `frontend/components/`
(only if an API change forces it), `i18n/{en,ja}/frontend.toml`. Common rules: `docs/tasks/README.md`.

**Read:** `frontend/README.md`, `frontend/core/*.qml`, `docs/PROTOCOL.md` (frozen v1, all),
`crates/kurashid/src/{main.rs,wiring.rs}` (documents and actions the daemon serves:
`theme, i18n, config, schema.settings, svc.workspaces, svc.media, svc.power, svc.session,
svc.network, svc.brightness, svc.notifications, runtime.island.main, runtime.ui, mods`; actions
`island.*`, `media.*`, `notify.*`, `launcher.launch`, `profile.*`, `mod.*`, `workspace.focus`).

**Build:**
1. `Store`: `Store.watch(doc)` / `Store.unwatch(doc)` with **refcounting** (first watcher subscribes,
   last unwatch unsubscribes — the daemon then stops the backing service, Ma); `Store.docs[doc]`
   reactive; `unknown_doc` errors leave the doc absent (no crash, no retry storm);
   `Store.query(kind, q, callback)` with stale-id dropping; `Store.act(action, args)` returning a
   promise-like callback with `done.data`/`err`; `Store.intent(...)` unchanged. Resubscribe all
   watched docs on reconnect and when `welcome.instance` changes.
2. `I18n` fills `strings` from the `i18n` document (fallback: key). `Theme` unchanged except reading
   via `Store.docs.theme`.
3. Surfaces watch what they render instead of a global subscription list (Bar: theme, svc.clock if
   present else a daemon-free clock is NOT allowed — show nothing; workspaces; media; island; ui).
   Note: the real daemon has no `svc.clock` yet — add a CONTRACT-CHANGE row requesting it (minute
   patches, PROTOCOL §8 shape) and render the clock face empty until it exists.
4. Island reason `manual` (new from the arbiter) treated like `user`.
5. A `frontend/test-real.sh`: sandbox + real `kurashid` with isolated XDG dirs and the sandbox's
   `DBUS_SESSION_BUS_ADDRESS` + `qs -p frontend`, screenshots: bar idle, island after
   `kurashi act island.next`, popup after `kurashi act island.expand`, disconnected veil after
   killing the daemon, reconnected after restarting it.

**Acceptance:** `frontend/test-real.sh` exits 0 with the 5 screenshots (verify them), and
`python3 tools/bench/measure.py --name frontend --warmup 10 --idle 30 -- qs -p frontend`
(mock) still passes: idle_commits_per_s ≤ 0.05, popup/morph non-null, pss_mib_popup ≤ 150.
